# Rocket Equation Calculator

A basic educational Python project that calculates the ideal velocity change (delta-v) of a rocket using the **Tsiolkovsky rocket equation**. Built as a self-learning project in mechanical and aerospace engineering fundamentals.

> **Note:** This is an ideal-case calculator. It does not include air drag, gravity losses or steering losses, so real rockets need more delta-v than the calculated value.

## The Equation

```
delta_v = Isp × g₀ × ln(m₀ / m_f)
```

| Symbol | Meaning | Unit |
|--------|---------|------|
| Δv | Change in velocity | m/s |
| Isp | Specific impulse of the engine | s |
| g₀ | Standard gravity (9.81) | m/s² |
| m₀ | Starting mass (rocket + fuel) | kg |
| m_f | Final mass (after fuel is burnt) | kg |

## Features

- Single-stage calculation: delta-v, mass ratio and propellant fraction
- Two-stage rocket calculation (total delta-v)
- Comparison with the ~9.4 km/s needed to reach low Earth orbit (LEO), including losses
- Graph of delta-v against mass ratio, saved as an image

## Requirements

- Python 3.8 or newer
- matplotlib

Install the dependency:

```bash
pip install -r requirements.txt
```

## How to Run

```bash
python rocket_equation_calculator.py
```

Choose `1` for a single stage or `2` for two stages, then enter the values when asked.

## Example (Single Stage)

Input: Isp = 300 s, m₀ = 100,000 kg, m_f = 10,000 kg

Delta-v            : 6776.5 m/s (6.78 km/s)

## Example (Two Stage)

| Stage | Isp (s) | Starting mass (kg) | Final mass (kg) |
|-------|---------|--------------------|-----------------|
| 1 | 300 | 100,000 | 30,000 |
| 2 | 350 | 20,000 | 3,000 |

Total delta-v ≈ **10,057 m/s (10.06 km/s)**, which is about 107% of the approximate LEO requirement in the ideal case.

For stage 2, enter its own starting mass, because stage 1 is dropped after burnout.

## What I Learned

- How the rocket equation links engine efficiency and mass ratio to the velocity a rocket can reach
- Why staging helps: dropping empty mass improves the mass ratio
- Why real rockets need more delta-v than the ideal value (drag and gravity losses)
- Writing and organising a small Python program using functions and a graph
